# Game data sources

[Home](README.en.md) · [简体中文](RESOURCES.md)

Start with the launch instructions for each game. Browser editions, downloadable packages and source builds can have different data requirements; entries that need original files name them explicitly.

## Data sources for homepage projects

| Project | How to obtain its data |
| --- | --- |
| [OpenTTD](https://www.openttd.org/downloads/openttd-releases/latest) | Download free [OpenGFX graphics](https://www.openttd.org/downloads/opengfx-releases/latest) on first run; OpenSFX and OpenMSX are available in-game. No original Transport Tycoon files required. |
| [OpenRA](https://www.openra.net/download/) | First-run setup can download the selected mod’s basic assets; see the [official description](https://www.openra.net/about/). |
| [Warzone 2100](https://wz2100.net/) | Official packages provide the basic game resources; campaign videos have a separate download. |
| [Diablo Web demo](https://d07riv.github.io/diabloweb/) | The page downloads shareware data. Only the demo is featured here; full play still needs your DIABDAT.MPQ. |

Projects in Run in browser load their resources without a manual ROM import. Build from source entries may still require original ROMs, discs or installed data; compiling does not supply these files. Build instructions do not certify an independently completed build or gameplay test.

## ROM and game-data websites

A ROM’s region, revision, patch state, format and hash must match the particular port. A general directory is not a verified data download for a specific project.

| Source | What it provides | Limitations |
| --- | --- | --- |
| [itch.io Homebrew](https://itch.io/games/tag-homebrew) | Creator-published games, some with NES, GB or GBA ROMs; [Böbl](https://morphcatgames.itch.io/bobl) explicitly includes its ROM. | Follow each creator’s terms. Homebrew ROMs cannot replace another commercial game’s data. |
| [PDRoms files](https://pdroms.de/files) | Multiplatform homebrew and independently released software. | Check the original author, files and terms for each release. |
| [Internet Archive Software Library](https://archive.org/details/softwarelibrary) | Third-party software and game archives, some with downloads or browser execution. | Files, restrictions and permissions vary by item; the archive is not a blanket publisher-authorized source. |
| [Edge Emulation](https://edgeemu.net/) | A third-party ROM directory with GB/GBA, N64, SNES and other platform categories. | Individual files, permissions and port compatibility require separate verification. |
| [/r/Roms directory](https://r-roms.github.io/General/ddl) | A platform-organized index of third-party resources, including Internet Archive and Edge Emulation. | A discovery source, not a guarantee of availability, permission or safety for an individual game. |

[Myrient’s original site](https://myrient.erista.me/) announces that it closed on March 31, 2026; it is not recommended as an available download source.

## Original PC game data

PC ports often need files from an installed game rather than a console ROM. Examples include [Diablo + Hellfire on GOG](https://www.gog.com/en/game/diablo), with DIABDAT.MPQ extraction covered by [DevilutionX](https://devilutionx.com/mpq), and [Half-Life on Steam](https://store.steampowered.com/app/70/HalfLife/). Check the particular port’s supported edition before buying.

Source builds may still need original files. Follow the project instructions for the supported data version. This collection hosts no original ROMs, disc images or game data.
